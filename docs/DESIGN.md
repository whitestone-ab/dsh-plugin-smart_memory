把「思考」看成一个**多模块循环加工系统**：不是先记忆再思考，而是注意把信息调进
工作记忆，工作记忆向长期记忆要原料，执行控制按目标操作，海马/皮层按图式重构，
情绪价值给权重，元认知做校验，结果再写回记忆。

## 1. 总原则

1. **工作记忆是思考的「黑板」**：容量有限，所有模块围绕它竞争。
2. **长期记忆是「原料库 + 模板库 + 偏见源」**：提供事实、经验、技能、图式，也带来定势。
3. **海马不是硬盘，是「索引与重构器」**：按线索模式补全，按当前目标重构。
4. **前额叶是「调度员」**：维持目标、抑制干扰、切换规则、监控冲突。
5. **情绪 / 价值是「权重旋钮」**：决定什么被注意、被提取、被采信。
6. **思考会回写记忆**：编码、复述、提取、再巩固都会改变记忆。

## 2. 模块清单

### 模块 1 · 注意门控 —— 决定「什么能进思考」

- **作用**：从感觉输入和记忆流中筛选相关信息，抑制无关信息。
- **影响**：注意什么，决定工作记忆里有什么；工作记忆里有什么，决定思考用什么。
- **被影响**：目标、情绪、突显性、旧图式会反向引导注意。
- **关键点**：思考偏差常从「注意选择」开始，不是从推理开始。

### 模块 2 · 工作记忆 —— 思考的中央黑板

- **作用**：暂存并操作当前信息，如心算、比较、推理、规划。
- **容量**：有限，约几个组块；组块化能扩容。
- **相互影响**：
  - 从长期记忆调取「组块、图式、规则」来降低负荷；
  - 执行控制决定黑板上保留什么、丢掉什么；
  - 负荷过高时，人更依赖直觉和旧习惯。
- **一句话**：工作记忆是记忆与思考的实时接口。

### 模块 3 · 情景记忆 —— 提供「具体经历」

- **作用**：记住何时何地发生什么，给思考提供案例、证据、自我叙事。
- **影响思考**：容易提取的案例会被高估（可得性启发）；鲜明情绪事件影响判断。
- **被思考影响**：回忆时按当前目标重构，细节可能被改写；反复提取会再巩固。
- **关键**：情景记忆不是录像，是「可重构的场景」。

### 模块 4 · 语义记忆 —— 提供「概念和事实」

- **作用**：概念、类别、规则、常识，是推理和分类的底料。
- **影响思考**：概念边界决定你怎么分类问题；语义网络决定联想速度。
- **被思考影响**：深度加工、建立因果链、总结归类，会让语义记忆更有结构。
- **关键**：语义记忆越有组织，思考越快；但概念僵化会限制新解。

### 模块 5 · 程序性记忆 —— 提供「自动化技能」

- **作用**：骑车、打字、熟练操作，释放工作记忆资源。
- **影响思考**：熟练带来效率，也带来定势；自动化反应可能绕过审慎思考。
- **被思考影响**：刻意练习、反思复盘会优化程序，但自动化后较难改写。
- **关键**：它是「快思考」的底层支撑。

### 模块 6 · 图式 / 脚本 —— 思考的「模板和预测器」

- **作用**：把过去经验压缩成预期结构，如「餐厅脚本」「考试脚本」。
- **影响思考**：
  - 加速理解、填补空白、做预测；
  - 导致同化偏差：把新信息硬塞进旧框架；
  - 可能把图式中存在但未发生的细节误记进记忆。
- **被思考影响**：反思和反例会修改图式。
- **关键**：图式是效率来源，也是偏见来源。

### 模块 7 · 执行控制 / 前额叶 —— 思考的「调度员」

- **作用**：维持目标、更新信息、抑制干扰、切换规则、解决冲突。
- **三个核心操作**：
  - **更新**：把新信息换进工作记忆；
  - **抑制**：压住无关记忆和冲动；
  - **切换**：在规则 / 视角间转换。
- **相互影响**：
  - 前额叶根据目标控制海马提取：要「要点」还是「细节」；
  - 抑制失败时，旧记忆和偏见更容易侵入；
  - 认知灵活性高，思考不易被定势锁死。
- **关键**：执行控制不是「更用力想」，而是「选择、压制、切换」。

### 模块 8 · 海马索引与重构 —— 记忆的「检索器和拼接器」

- **作用**：
  - **模式完成**：给一个线索，补全整个场景；
  - **模式分离**：区分相似经历，避免混淆；
  - **重构**：按当前目标和图式重新拼接记忆片段；
  - **离线回放**：睡眠 / 休息时重演序列，支持巩固和规划。
- **相互影响**：
  - 前额叶给目标，海马按目标提取；
  - 海马给细节，皮层给图式，二者协商出「记得的故事」；
  - 每次提取都可能再巩固，思考因此能改写记忆。
- **关键**：海马是「索引 + 重构器」，不是精确硬盘。

### 模块 9 · 默认网络 / 联想系统 —— 发散思考的「背景流」

- **作用**：回忆过去、想象未来、自发联想、整合远距离信息。
- **影响思考**：
  - 支持创造力、类比、洞察；
  - 连接过强可能走神、跳跃；
  - 与执行网络协同，才能「发散后收敛」。
- **相互影响**：执行控制给约束，默认网络给候选；约束太强则僵，太弱则散。

### 模块 10 · 情绪 / 价值 / 动机 —— 权重与门控

- **作用**：给信息打「重要性、威胁性、奖励性」标签。
- **影响**：
  - 决定注意和提取优先级；
  - 情绪记忆更易巩固，也易扭曲；
  - 压力下偏向习惯和直觉，削弱工作记忆。
- **被思考影响**：重新评价、反思意义会改变记忆的情绪色彩。
- **关键**：情绪不是干扰项，是权重系统。

### 模块 11 · 元认知监控 —— 思考的「质检员」

- **作用**：判断「我记得准不准」「这个推理有没有漏洞」「我是否理解」。
- **影响**：
  - 决定是否采信某段记忆；
  - 触发更多提取或修正；
  - 监控失败会导致「流畅即真实」的错觉。
- **相互影响**：元认知校准好，记忆重构偏差更易被拦住；校准差，偏见会被当成事实。

### 模块 12 · 编码与再巩固 —— 思考结果「回写」记忆

- **作用**：把思考产物写回长期记忆。
- **机制**：
  - 深度加工、精加工、自我关联、组织化提高编码；
  - 提取后记忆短暂不稳定，再巩固可修改；
  - 睡眠回放促进海马 → 新皮层系统巩固。
- **相互影响**：思考越深，记忆越牢；但重述也可能植入错误。
- **关键**：这是「思考改变记忆」的入口。

## 3. 把模块串成一个思考流程

```text
① 注意门控        目标 / 情绪 / 突显性筛选信息
      ↓
② 工作记忆        把信息放上黑板
      ↓
③ 长期记忆提取    语义给概念，情景给案例，程序给技能，图式给模板
      ↓
④ 海马重构        按线索和目标补全、拼接记忆片段
      ↓
⑤ 前额叶操作      比较、推理、抑制干扰、切换视角、更新黑板
      ↓
⑥ 默认网络联想    提供远距离候选、类比、洞察
      ↓
⑦ 情绪价值加权    什么重要、什么可信、什么该优先
      ↓
⑧ 元认知校验      检查记忆可信度、推理一致性、理解程度
      ↓
⑨ 输出 / 行动     决策、表达、执行
      ↓
⑩ 回写记忆        编码、复述、再巩固，改变下次提取
      ↺ 回到 ①，形成循环
```

## 4. 关键相互影响机制

### 4.1 记忆 → 思考的四种方式

- **供料**：概念、事实、案例、技能；
- **供模板**：图式 / 脚本加速理解；
- **供线索**：联想网络决定想到什么；
- **供偏见**：可得性、定势、情绪记忆扭曲判断。

### 4.2 思考 → 记忆的四种方式

- **选择编码**：关注什么就记什么；
- **组织编码**：分类、因果链、总结让记忆更可提取；
- **控制提取**：按目标要细节或要点；
- **重构改写**：提取即重构，再巩固可改内容与情绪意义。

### 4.3 三个核心瓶颈

- **工作记忆容量**：决定同时能操作多少；
- **执行控制抑制力**：决定旧记忆 / 冲动能否被压住；
- **元认知校准**：决定错误记忆和错误推理能否被拦住。

### 4.4 两个相反力量

- **图式化 / 自动化**：提高效率，但造成定势；
- **认知控制 / 反思**：打破定势，但耗资源。

思考质量取决于二者能否动态切换。

## 5. 一个例子：解决新问题

你遇到新问题：**注意**先抓住关键线索 → **工作记忆**保持目标 → **语义记忆**给概念 →
**情景记忆**给类似案例 → **图式**给常规解法 → **前额叶**发现常规解法不通，抑制旧方案 →
**默认网络**做类比联想 → **海马**重构相关片段 → **情绪**标记哪个方案有希望 →
**元认知**检查漏洞 → 得出新方案 → **编码 / 再巩固**把这次经验写回记忆。

下次再遇类似问题，提取更快，但也可能形成新定势。

## 6. 一句话总结

> **思考过程 = 注意筛选 → 工作记忆维持 → 长期记忆供料 → 海马重构 → 前额叶调度
> → 默认网络发散 → 情绪加权 → 元认知质检 → 输出 → 回写记忆。**

记忆给思考**内容、模板和偏见**；思考给记忆**选择、组织、提取和改写**；
二者通过工作记忆、执行控制、海马重构和再巩固不断循环塑造。
